CoolProp API 服务

欢迎使用基于 Python 和 CoolProp 构建的物性计算 API 服务。

📚 Swagger 交互式文档 📖 ReDoc 文档

API 使用说明

GET /props

计算流体的热力学性质。

请求参数 (Query Parameters)

  • fluid (必填): 流体名称，例如 "Water", "Nitrogen", "R134a"。
  • out_prop (必填): 需要计算的输出属性代码，例如 "H" (焓), "S" (熵), "D" (密度)。
  • in_prop1 (必填): 第一个已知属性代码，例如 "P" (压力)。
  • in_val1 (必填): 第一个已知属性的数值。
  • in_prop2 (必填): 第二个已知属性代码，例如 "T" (温度)。
  • in_val2 (必填): 第二个已知属性的数值。

请求示例

计算在 101325 Pa 和 300 K 下水的密度：

GET /props?fluid=Water&out_prop=D&in_prop1=P&in_val1=101325&in_prop2=T&in_val2=300

响应示例

{
  "fluid": "Water",
  "requested_property": "D",
  "value": 996.556,
  "unit": "kg/m^3 (approx)"
}

支持的属性代码参考

  • T : 温度 (K)
  • P : 压力 (Pa)
  • H : 质量焓 (J/kg)
  • S : 质量熵 (J/kg/K)
  • D : 质量密度 (kg/m^3)
  • Q : 质量蒸汽品质 (mol/mol 或 kg/kg)

更多详情请参考 CoolProp 官方文档。
