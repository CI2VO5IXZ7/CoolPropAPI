湿空气物性计算 API

基于 FastAPI + CoolProp 构建，专为焓湿图 (h-d chart) 计算设计。支持 ℃ 和 kJ/kg 等工程常用单位直接输入输出。

📚 Swagger 交互式文档 📖 ReDoc 文档 🔑 查看属性代码

一、接口一览

GET/haprops

计算单点湿空气物性。直接把已知属性作为查询参数名。

POST/haprops/batch

批量计算（绘制焓湿图等）。JSON Body 传入多组状态点。

GET/haprops/keys

查询所有可用的属性代码与单位说明。

GET/health

健康检查。

三、GET 调用方式

调用格式非常直观：需要的物性作为 out_prop，已知的三个状态参数直接作为 URL 查询参数（参数名即 CoolProp 属性代码）。

💡 单位约定 (已自动换算)
  • 温度 (T, Twb, Tdp) 输入输出均为 ℃
  • 焓值 (H, Hda) 输入输出均为 kJ/kg 绝干气
  • 压力 P 单位为 Pa
  • 相对湿度 R 取值范围 0 ~ 1
  • 含湿量 W 单位为 kg 水蒸气 / kg 绝干气

示例 1：已知干球温度 + 相对湿度，求焓值

GET /haprops?out_prop=H&P=101325&T=25&R=0.5
{
  "requested_property": "H",
  "inputs": { "P": 101325, "T": 25, "R": 0.5 },
  "value": 50.42,
  "status": "success"
}

示例 2：已知干球温度 + 湿球温度，求相对湿度

GET /haprops?out_prop=R&P=101325&T=30&Twb=22

示例 3：已知焓值 + 含湿量，求干球温度

GET /haprops?out_prop=T&P=101325&H=50&W=0.01

示例 4：求露点温度

GET /haprops?out_prop=Tdp&P=101325&T=30&R=0.6

四、POST 批量调用 (焓湿图绘制)

对于绘制焓湿图，通常需要计算大量等值线上的点。使用批量接口可以一次性获得结果。

POST /haprops/batch
Content-Type: application/json

{
  "out_prop": "W",
  "points": [
    { "inputs": { "P": 101325, "T": 20, "R": 0.5 } },
    { "inputs": { "P": 101325, "T": 25, "R": 0.5 } },
    { "inputs": { "P": 101325, "T": 30, "R": 0.5 } }
  ]
}

curl 示例：

curl -X POST https://coolpropapi.zeabur.app/haprops/batch \
  -H "Content-Type: application/json" \
  -d '{"out_prop":"W","points":[{"inputs":{"P":101325,"T":25,"R":0.5}}]}'

五、属性代码对照表

代码含义单位类别
P压力Pa输入/输出
T / Tdb干球温度℃输入/输出
Twb / B湿球温度℃输入/输出
Tdp / D露点温度℃输入/输出
R相对湿度0 ~ 1输入/输出
W含湿量kg/kg 绝干气输入/输出
H / Hda湿空气比焓kJ/kg 绝干气输入/输出
V / Vda比容m³/kg 绝干气输入/输出
S / Sda比熵J/(kg·K)输入/输出
Y / psi_w水蒸气摩尔分数mol/mol输入/输出
