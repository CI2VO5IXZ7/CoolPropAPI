CoolProp API 服务

欢迎使用基于 Python 和 CoolProp 构建的物性计算 API 服务。

📚 Swagger 交互式文档 📖 ReDoc 文档

API 使用说明

GET /haprops

计算湿空气的热力学性质，特别适用于绘制或计算焓湿图数据。

请求参数 (Query Parameters)

  • out_prop (必填): 需要计算的输出属性代码，例如 "H" (焓, kJ/kg), "W" (含湿量, kg/kg), "V" (比容, m³/kg)。
  • 直接提供另外三个已知属性代码作为参数名，并赋予其对应的数值。例如: P=101325, T=25, R=0.5。必须且仅需提供三个。

注意： 本接口已经自动处理了常用单位转换：

  • 所有温度 (代码 T, Twb, Tdp) 输入和输出单位均为 ℃ (摄氏度)
  • 所有焓值 (代码 H, Hda) 输入和输出单位均为 kJ/kg
  • 压力单位仍为 Pa

请求示例

计算在 101325 Pa 大气压、干球温度 25 ℃ 且相对湿度为 50% (0.5) 时湿空气的焓值 (kJ/kg)：

GET /haprops?out_prop=H&P=101325&T=25&R=0.5

响应示例

{
  "requested_property": "H",
  "inputs": {
    "P": 101325.0,
    "T": 25.0,
    "R": 0.5
  },
  "value": 50.41,
  "status": "success"
}

湿空气属性代码参考

  • T : 干球温度 (℃)
  • Twb : 湿球温度 (℃)
  • Tdp : 露点温度 (℃)
  • P : 压力 (Pa)
  • H : 湿空气比焓 (kJ/kg 绝干气)
  • W : 含湿量 (kg 水蒸气 / kg 绝干气)
  • R : 相对湿度 (0 ~ 1)
  • V : 湿空气比容 (m³/kg 绝干气)

更多详情请参考 CoolProp 湿空气文档。
