湿空气物性计算 API

基于 FastAPI + CoolProp。给定任意 2 个状态参数，一次返回该状态点的全部湿空气物性，由调用方按需取用。

一、调用规则

  1. 请求方式：HTTP GET（单点）或 POST（批量），均返回 JSON。
  2. 查询参数名直接使用属性代码（见第三节），值为该属性的数值。
  3. 必须且只能提供 2 个状态参数（多 1 或少 1 → 400）；同义代码（如 T 与 Tdb）不能同时出现（→ 400）。
  4. 输入越界直接返回 400：P 50000 ~ 110000 Pa；温度类 −100 ~ 200 ℃；R 0 ~ 1；W 0 ~ 0.1；H −100 ~ 500 kJ/kg。
  5. 限流：每个 IP 每分钟合计 60 次（/chart/hd 单独每分钟 10 次），超出返回 429。默认按直连地址计数，伪造 X-Forwarded-For 不能换配额。只有部署时设置 TRUST_PROXY=1 或 TRUST_PROXY_HOPS≥1，才按该头从右数第 N 个地址限流；地址不够 N 个时仍按直连地址。
  6. 压力 P 是可选参数，缺省 101325 Pa（标准大气压）；如需非标压（高原、加压舱等）显式传入即可。
  7. 响应中 state 字段包含该状态点的全部物性，前端自取所需字段。
  8. 温度统一 ℃，焓统一 kJ/(kg 干空气)，相对湿度 0~1（小数）。

URL 结构拆解

https://your-host/ha?T=25&R=0.5
主机 服务地址 路径 唯一计算端点 状态参数 任意 2 个 P 可选，缺省 101325 Pa

含义：在标准大气压、干球温度 25 ℃、相对湿度 50% 下，求湿空气全部物性。

二、单点调用 GET /ha

请求格式

GET /ha?<键1>=<值1>&<键2>=<值2>[&P=<Pa>]

响应格式

{
  "inputs":   { "<键1>": <值1>, "<键2>": <值2> },
  "pressure": { "P": 101325, "default": true },   // default=true 表示用了缺省值
  "state": {
    "T": ..., "Twb": ..., "Tdp": ...,
    "R": ..., "W": ...,
    "H": ..., "V": ...,
    "S": ..., "Y": ...
  }
}

state 中个别字段若 CoolProp 解算失败，会返回 null，不会阻断其他字段。

示例 1：标准大气下，已知 T + R

GET /ha?T=25&R=0.5
{
  "inputs":   { "T": 25, "R": 0.5 },
  "pressure": { "P": 101325, "default": true },
  "state": {
    "T":   25.00,
    "Twb": 17.88,
    "Tdp": 13.87,
    "R":   0.50,
    "W":   0.00993,
    "H":   50.42,
    "V":   0.8578,
    "S":   180.76,
    "Y":   0.01571
  }
}

示例 2：非标压（高原 80 kPa）

GET /ha?T=25&R=0.5&P=80000

响应中 pressure.default 为 false，表示已被显式覆盖。

示例 3：已知干球 + 湿球温度

GET /ha?T=30&Twb=22

示例 4：已知比焓 + 含湿量（焓湿图反查）

GET /ha?H=50&W=0.01

curl 调用

curl "https://your-host/ha?T=25&R=0.5"

三、参数（属性代码）含义

下表中同义代码任选其一。P 为可选项，其余均为状态参数。

代码物理含义单位 / 取值典型范围同义代码
P湿空气总压力（绝压，可选）Pa50000 ~ 110000，缺省 101325—
T干球温度℃−100 ~ 200Tdb
Twb湿球温度（绝热饱和温度）℃≤ TB
Tdp露点温度℃≤ TD
R相对湿度0 ~ 1（小数，非百分数）0.5 即 50%—
W含湿量（绝对湿度）kg 水 / kg 干空气0 ~ 0.05—
H湿空气比焓kJ / kg 干空气−50 ~ 200Hda
V比容m³ / kg 干空气≈ 0.7 ~ 1.0Vda
S比熵J / (kg·K)—Sda
Y水蒸气摩尔分数mol / mol0 ~ 1psi_w
💡 易错点
  • 相对湿度 R 用 小数（0.5 表示 50%）。
  • 温度类一律 ℃，不要传开尔文。
  • 焓一律 kJ/kg，不要传 J/kg。
  • 压力 P 单位 Pa，不要传 kPa。
  • 状态参数恰好 2 个；同义代码（如同时给 T 和 Tdb）直接返回 400。

四、批量调用 POST /ha/batch

用于一次计算多个状态点（绘焓湿图、批量工况扫描等）。每个点独立解析、独立容错。单次最多 500 个点，超过返回 400。

请求格式

POST /ha/batch
Content-Type: application/json

{
  "points": [
    { "T": 20, "R": 0.5 },
    { "T": 25, "R": 0.5 },
    { "T": 30, "R": 0.5, "P": 80000 }
  ]
}

响应格式

{
  "count": 3,
  "results": [
    {
      "index": 0,
      "inputs": { "T": 20, "R": 0.5 },
      "pressure": { "P": 101325, "default": true },
      "state": { "T": 20.00, "Twb": 13.78, ... },
      "status": "success"
    },
    ...
    {
      "index": 2,
      "inputs": { "T": 30, "R": 0.5 },
      "pressure": { "P": 80000, "default": false },
      "state": { ... },
      "status": "success"
    }
  ]
}
单个点失败不会中断整体请求；该点 status="error" 并附带 error 字段，其余点继续返回。

curl 调用

curl -X POST https://your-host/ha/batch \
  -H "Content-Type: application/json" \
  -d '{"points":[{"T":25,"R":0.5},{"T":30,"R":0.6}]}'

五、焓湿图 GET /chart/hd

生成国标样式 h-d 焓湿图（斜角坐标：横轴含湿量 d，等温线近水平、等焓线向右下斜交约 135°），可直接在浏览器打开或嵌入报告。所有曲线数值与 /ha 同源（CoolProp）。

参数默认范围说明
p10132550000 ~ 110000 Pa总压
t_min / t_max−10 / 45−30 ≤ t_min < t_max ≤ 60 ℃，跨度 ≥ 10温度范围
d_max305 ~ 60 g/kg横轴上限
fmtpngpng | svg输出格式
width1200600 ~ 2400 pxPNG 宽度，高度按比例
points—≤ 10 个，T,R;T,R（℃, 0~1）在图上标注状态点
langzhzh | en标签语言；服务器缺中文字体时自动回退 en（响应头 Content-Language）
 
GET /chart/hd
GET /chart/hd?fmt=svg&points=25,0.5;30,0.6
GET /chart/hd?p=80000&t_min=0&t_max=35&d_max=25&lang=en

预览（标注 25 ℃ / 50%，落在 d ≈ 9.93 g/kg、h ≈ 50.4 kJ/kg）：

越界参数返回 400 JSON {"detail": ...}；响应带 Cache-Control: public, max-age=86400；每个 IP 每分钟最多 10 次。

六、辅助接口

GET /ha/keys

返回服务端支持的全部状态参数代码、输出字段列表与单位说明，便于客户端动态构造表单。

GET /health

返回服务名与版本号，用于探活。

{ "status": "ok", "service": "CoolProp API", "version": "2.0.0" }

七、错误响应

// 状态参数个数不是 2
HTTP 400
{ "detail": "需要且仅需 2 个状态参数（除 P 之外），当前提供了 1 个" }

// 属性代码非法
HTTP 400
{ "detail": "存在无效的属性代码: ['XYZ']。有效代码见 /ha/keys" }

// 参数值不是合法数字
HTTP 400
{ "detail": "参数 T 的值 'abc' 不是有效的数字" }

// 输入越界
HTTP 400
{ "detail": "参数 R 的值 1.5 超出允许范围 [0, 1]" }

// 同义参数冲突
HTTP 400
{ "detail": "参数 T 与 Tdb 为同义参数，不能同时提供" }

// batch 超过 500 点
HTTP 400
{ "detail": "批量点数 501 超过上限 500" }

// 请求过于频繁
HTTP 429
{ "detail": "请求过于频繁，请稍后再试（限制：60 per 1 minute/IP）" }

// CoolProp 内部错误（输入组合不一致 / 越界等）
HTTP 500
{ "detail": "计算错误: ..." }
